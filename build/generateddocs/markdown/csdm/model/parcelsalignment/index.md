
# CSDM Cadastral Parcels Alignment (Model)

`icsm.csdm.model.parcelsalignment` *v0.2*

Deprecates the terms of the retired CSDM Cadastral Parcels module and maps each to the OGC Land Parcels term that replaces it, so the CSDM parcels IRIs still resolve.

[*Status*](http://www.opengis.net/def/status): Under development

* [3D CSDM model source (icsm-au/3d-csdm, csdm_model/parcels.ttl)](https://github.com/icsm-au/3d-csdm/blob/main/csdm_model/parcels.ttl)
